A guide from Tyler

Set Up Your Ledgr

Ledgr is a personal system for your meetings, tasks, notes, and projects — your own private copy, running on your own free accounts. You don't need to be technical: Claude does the work, and you sign in to a few websites when it asks.

Time: 30–45 minutes Cost: $0 — everything runs on free plans You need: your own computer, your email, and Claude Code
Most of this guide is the same little dance, once per account: you create the account → you give Claude permission to use it (a browser window pops up; you click Allow) → Claude does everything else on that account for you. Four accounts, four dances, then Claude builds your Ledgr.
Don't have Claude Code yet?

Claude Code is the assistant that does the technical work. Ask Tyler to help you install it, or paste one of these into a command window and sign in with a free Claude account when it asks:

Mac (Terminal):
curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell):
irm https://claude.ai/install.ps1 | iex
1
You do this

Install Node — the installer for everything else

Node is the tool Claude uses to install and run all the other tools, so it goes in first. Copy the command for your computer, paste it into your command window, and press Enter.

On a Mac — open Terminal (press ⌘ Space, type “Terminal”, press Enter)

This downloads the official Node installer and opens it — click through it:

curl -o ~/Downloads/node.pkg https://nodejs.org/dist/v24.19.0/node-v24.19.0.pkg && open ~/Downloads/node.pkg
On Windows — open PowerShell (press Start, type “PowerShell”, press Enter)
winget install OpenJS.NodeJS.LTS

Then: close the command window, open a fresh one, type claude, and press Enter. Everything from here on is pasted to Claude in that window.

Important: use your own computer. The setup signs into your accounts, so a borrowed or shared computer will tangle things up.

You + Claude

GitHub — where your copy of Ledgr lives

Paste this to Claude. It opens the GitHub sign-up page and waits while you create your account. Then Claude installs GitHub's tool, you grant it permission, and Claude makes your own copy of the Ledgr code for you.

I'm setting up my own Ledgr (step 2 of Tyler's guide: GitHub). First, open https://github.com/signup in my browser and wait while I create a GitHub account — if I say I already have one, skip ahead. Then install GitHub's command-line tool (gh) and connect my account: run gh auth login --web, show me the short code, and wait while I enter it in the browser and click Authorize. Once connected, make my copy of the Ledgr code for me: run gh repo fork strategicli/ledgr --clone=false, then confirm the fork exists and tell me my GitHub username.

What you'll see: the sign-up page, then Claude shows you a short code (like ABCD-1234) — a GitHub page opens, you type the code in and click Authorize. Claude handles the rest.

Vercel — runs the app on the internet

Paste this to Claude. It installs Vercel's tool and pops open the connection page.

Next account for my Ledgr setup (step 3: Vercel). Install Vercel's command-line tool and connect my account: run npx -y vercel@latest login and wait — a browser window will open and I'll sign up by clicking "Continue with GitHub" and allow the connection. When it finishes, confirm I'm connected by running npx -y vercel@latest whoami.

What you'll see: a Vercel page — click Continue with GitHub (no new password to remember), then Allow/Authorize.

Neon — the database where your items live

Next account for my Ledgr setup (step 4: Neon). Install Neon's command-line tool and connect my account: run npx -y neonctl@latest auth and wait — a browser window will open and I'll sign up (I'll use "Continue with GitHub") and click Allow. When it finishes, confirm I'm connected by running npx -y neonctl@latest me.

Sign in to your new Ledgr

      
When Claude says the setup is verified, it gives you your address — something like yourname‑ledgr.vercel.app. Open it, sign up using exactly the email address from step 6, and you're in. Bookmark it; on your phone you can add it to your home screen like an app.

      You do this — later, whenever
      
Getting updates

      
Ledgr keeps improving, and your copy was set up to take updates safely. When you want the latest: inside Ledgr, go to Build → Updates and press the button if one is offered. That's the whole thing — no terminal, no Claude. If an update ever has a problem, your current version simply stays running.

      
Claude also ends the setup with a short summary block — keep a screenshot of it somewhere safe, and share it with Tyler if he asks (he can help if anything ever needs fixing).

    

  


  

    
If something looks wrong

    

      
A browser window didn't pop up

      
Tell Claude. It can print the link instead — copy it into your browser yourself and carry on.

      
“Signed in, but not recognized”

      
The email you signed in with isn't the one from step 6. Tell Claude: “I signed in with a different email address, fix the owner email to ___” and it will.

      
A step failed or Claude seems stuck

      
Just tell Claude what you see on the screen. It can read error messages and try again. Nothing in this setup is fragile — steps can be safely re-run.

      
Uploading a photo or file doesn't work

      
That's expected for now — file storage is an optional extra that isn't part of the basic setup. Ask Tyler if you want it added.
